01Contexto del problema

Una pequeña fábrica de mermeladas artesanales cierra sus frascos a mano, presionando cada tapa contra la boca del frasco. El trabajo es lento y muchas tapas quedan mal puestas. Se pide diseñar el mando electroneumático de una estación tapadora que funcione así:

  1. El operador energiza el sistema con el pulsador de marcha S1. El pulsador S0 lo deshabilita.
  2. El operador pone un frasco en la base. El sensor B1 lo detecta y el ciclo comienza, siempre que ambos cilindros estén retraídos (a0 y b0).
  3. A+ · El cilindro A empuja la tapa inferior del almacén por el riel hasta dejarla sobre la boca del frasco.
  4. B+ · Cuando A llega al final (a1), el cilindro B baja y presiona la tapa hasta encajarla.
  5. A− · Cuando B llega abajo (b1), A retrocede para recibir la siguiente tapa. B mantiene la tapa presionada.
  6. B− · Cuando A está atrás (a0), B sube y el frasco queda tapado.
Condición: el frasco tapado sigue frente a B1, y el sistema no puede repetir el ciclo sobre él. El siguiente ciclo solo parte cuando el operador retira el frasco y pone uno nuevo. La velocidad de ambos cilindros debe poder regularse.

Designaciones obligatorias: cilindros A, B · posiciones a0 a1 b0 b1 · válvulas V1 (Y1 = A+, Y2 = A−) y V2 (Y3 = B+, Y4 = B−) · sensor B1 · pulsadores S0 S1 · relés K0, K1…
